====================================================================
                         C++ KEYWORDS
====================================================================

DEFINITION:
-----------
Keywords are reserved words in C++ that have a predefined/special
meaning for the compiler.

We CANNOT normally use a keyword as:
    - Variable name
    - Function name
    - Class name
    - Object name
    - Any other identifier

Example:
    int age = 20;

    int  -> keyword
    age  -> identifier
    20   -> literal

====================================================================
                  KEYWORD vs IDENTIFIER
====================================================================

KEYWORD:
    Reserved by C++
    Has predefined meaning
    Cannot normally be used as a name

IDENTIFIER:
    Name given by programmer
    Used for variables, functions, classes, etc.

Example:

    int marks = 90;

    int      -> KEYWORD
    marks    -> IDENTIFIER
    90       -> LITERAL

====================================================================
                         IMPORTANT NOTE
====================================================================

• C++ keywords are reserved words.
• Keywords are case-sensitive.

For example:

    int     -> keyword
    Int     -> NOT the keyword `int`
    INT     -> NOT the keyword `int`

However, `Int` and `INT` can be identifiers.
